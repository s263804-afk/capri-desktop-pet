# 角色素材与第三方权利 / Artwork and third-party rights

## 授权范围

根目录的 MIT 许可证适用于本项目新编写的工具、测试和项目说明文本。它不适用于：

- `assets/` 中的角色图集及其导出图像；
- `previews/` 中的 GIF、PNG、MP4 及其中呈现的角色图像；
- 原作的角色设计、世界观、名称、商标及第三方参考图。

本项目没有通过 MIT、Creative Commons 或其他开放许可证授予上述原作及第三方权利，也不主张对原作角色拥有权利。生成图像、制作流程及文件的公开提供不消除这些权利边界。

素材作为非官方同人创作供展示与交流。对原作、参考图或生成素材的再利用，应根据涉及的实际权利和适用规则确认；本仓库不授予原作相关商业使用许可，也不将其描述为官方授权桌宠。

CD PROJEKT RED 的公开同人指南包含非商业使用、明确标识非官方及其他要求；该指南不是本项目取得全部角色或动画相关权利的证明，也不保证覆盖所有第三方产品集成。

- [CD PROJEKT RED Fan Content Guidelines](https://www.cdprojektred.com/en/fan-content)
- [CD PROJEKT RED User Agreement](https://regulations.cdprojektred.com/en/user_agreement)

原始用户参考图的作者未获确认，因此不重新分发该图片；官方授权海报也只保留来源链接。若你是相关权利人或能补充准确署名，请通过项目 Issue 联系维护者。
