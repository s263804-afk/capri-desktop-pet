# 基础形象约束

为 Capri / 摩羯制作紧凑的全身 Q 版桌宠：巨大而不对称的红色／玫红色几何火焰头，黑色尖锐内轮廓，绿色屏幕状脸，两个蓝色同心圆数字眼睛，小型白色折线嘴。

发焰由主体和邻近的悬浮多边形碎片组成，保留断裂、透明间隙和火焰感；悬浮碎片是角色构造的一部分，不应作为杂点删除。头部只有细小稀疏的高光点，不加梯状反光条纹。

身体保持参考中的不对称红、黑、绿色几何图案：左侧绿色肩部、腰侧和大腿色块，另一侧以红黑为主。保持小身体和黑色尖脚，不添加夹克翻领、拉链、手套、靴子、护膝或对称的中央十字装饰。

采用平面贴纸画风、饱和色和清晰深色轮廓。全身及发焰碎片完整可见，四周有充足留白；无文字、网格、地面阴影、场景、额外道具或无关漂浮特效。透明背景，或使用与角色颜色充分区分的纯黄色底便于后期提取。

表情以俏皮、好奇、慵懒和疑惑为主要动作语汇。常态绿色脸，白色脸仅依照已见参考使用，不自行定义其他颜色的官方含义。
