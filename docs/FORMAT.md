# v2 图集格式

完整布局定义在 [`assets/manifest.json`](../assets/manifest.json)。

| 参数 | 数值 |
| --- | --- |
| 图集 | 1536 × 2288，透明 PNG |
| 单帧 | 192 × 208 |
| 网格 | 8 列 × 11 行 |
| 使用格位 | 73 |
| 留空格位 | 15，必须完全透明 |

行号从 0 开始。第 0–8 行的帧数依次为 `6, 8, 8, 4, 5, 8, 6, 6, 6`，有效帧从每行最左侧开始。行 7 的 `running` 表示主动工作／思考状态，行 1–2 才是朝左右移动。

第 9 行：`000, 022.5, 045, 067.5, 090, 112.5, 135, 157.5`。

第 10 行：`180, 202.5, 225, 247.5, 270, 292.5, 315, 337.5`。

角度为屏幕坐标：上为 0°，右为 90°，下为 180°，左为 270°，顺时针排列。正面休息姿态取普通待机帧，不另占视线格位。

## 工具检查什么

`pet_assets.py validate` 检查文件格式、20 MiB 限制、尺寸、有效格位是否有图像、近乎不透明的格位背景，以及留空格位是否完全透明。它不判断角色身份、动作含义、方向是否正确或动画是否流畅，也不替代 Pets 服务的导入校验。

`extract` 导出完整单元格，不做紧边裁切。`assemble` 原样复制 RGBA 像素，不使用透明混合覆盖，以保留半透明边缘。测试会检查真实图集导出再重组后的全部 RGBA 像素一致。
