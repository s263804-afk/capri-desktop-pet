# GitHub 项目介绍

## About（英文，适合仓库简介）

Unofficial Capri-inspired pet assets for ChatGPT/Pets: 9 animations, 16 gaze directions, a transparent v2 atlas, and Python frame tools.

## 中文简介

以《赛博朋克：边缘行者 2》Capri（摩羯）为灵感的非官方桌宠素材项目，保留悬浮断裂发焰、绿／白变色脸和不对称几何身体。包含 9 组动作、16 向视线、透明图集、动画预览和帧处理工具。
