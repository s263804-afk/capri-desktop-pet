# 来源与制作记录

## 视觉参考

- 用户提供的 Q 版表情图：用于比例、表情与断裂发焰的参考；原作者暂未确认，原始 JPEG 不随仓库分发。
- [官方授权 Capri 海报](https://displate.com/displate/11144097)：用于核对不对称红、黑、绿色身体图形；不分发海报原图，不将海报的授权状态延伸为本项目授权。
- [作品官网](https://www.cyberpunk.net/en/edgerunners2)：作品背景来源。

## 生成与修订

使用 OpenAI 内置图像生成工具制作基础形象、九组动作、四个主要视线姿态和两个八帧视线组。按状态分别生成，随后进行透明背景处理、组件提取、共同尺度注册与图集拼接。

第一版误加了夹克、靴子和对称条纹，并把发焰连成整块，已弃用。当前版本恢复不对称几何身体及悬浮火焰碎片。脸部只使用参考图中可见的绿色和白色，不声明完整的官方颜色／情绪映射。

向右视线曾更像低头，后来强化了脸和眼睛的横向移动，再重做整个上半圈视线。部分相邻中间角度依然接近，保留这一已知限制。

提示词简报位于 `prompts/`。它们记录角色约束和动作目标，并非全部交互的逐字日志；随机生成不能保证复现相同像素。

仓库中的处理脚本为本项目独立编写；不依赖或重新分发宿主应用的私有技能脚本。账号宠物 ID、上传会话、临时下载地址及本机路径不纳入发布内容。
